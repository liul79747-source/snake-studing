# 🐍 贪吃蛇小游戏

使用 HTML + CSS + JavaScript 实现的网页版贪吃蛇游戏。

## 🎮 游戏玩法

- 使用键盘方向键 ↑ ↓ ← → 控制蛇移动
- 吃到食物身体变长，分数增加
- 撞到墙壁或者撞到自己身体，游戏结束
